# 家計簿チャットボット UIスペック（スマホ優先 / かわいい淡色）

Version: 0.1
Last Updated: 2026-01-09 (Asia/Tokyo)

---

## 1. UI方針

- スマホ（片手・親指操作）前提
- 角丸カード + 淡いパステルカラー
- 主要導線は「入力 →（確認）→ 確定」を最短に
- 初見ユーザーでも迷わない（主婦層を想定）

---

## 2. 画面一覧（MVP）

### 2.1 ホーム（/）
**目的**: 入力の入口 + 当月サマリー

**コンポーネント**
- 入力カード
  - テキスト入力欄（複数行）
  - 送信ボタン（Primary）
  - ヒント文（例文）
- レシートカード
  - 画像選択（カメラ起動：`capture=environment`）
  - 送信ボタン（Primary）
- 当月サマリーカード
  - 支出合計 / 収入合計 / 収支
  - 「分析を見る」ボタン

**状態**
- loading: スピナー + "解析中…"
- success: トースト "記録しました"
- need_clarification: 質問カードを表示（ボタン回答優先）

---

### 2.2 履歴（/history）
**目的**: 月ごとの取引一覧を閲覧・修正

**コンポーネント**
- 月セレクタ（プルダウン + 左右ボタン）
- フィルタ（カテゴリ/支払方法/状態）
- 取引カードリスト
  - 日付、merchant、カテゴリ、金額
  - タップで詳細/編集へ

**詳細（モーダル or /history/:id）**
- category/subcategory（選択）
- amount（数値）
- payment_method（選択）
- memo
- 確定/修正ボタン

---

### 2.3 分析（/insights）
**目的**: 使いすぎ/節約などの気づきを提示

**コンポーネント**
- KPIカード（当月/前月）
- 円グラフ（カテゴリ別支出）
- 折れ線（過去12か月支出推移）
- インサイトカード
  - 使いすぎカテゴリTOP3（前月比 +金額）
  - 節約成功カテゴリTOP3
  - needs/wants比率（将来）

---

## 3. デザイン仕様（トーン）

### 3.1 色（例）
- Background: かなり薄いグレー/白（#F8FAFC系）
- Primary: 濃すぎないネイビー系（#111827相当）
- Accent（パステル）:
  - Blue: #DCEBFF
  - Pink: #FFE3EE
  - Mint: #DFF7EE
  - Lavender: #EEE6FF
  - Yellow: #FFF6D8

> 強い原色は避ける。コントラストはWCAG意識（文字は濃色）。

### 3.2 形
- 角丸: 12〜16px
- カード: 余白多め（読みやすさ優先）
- ボタン: 高さ 44px 以上（親指タップ）

### 3.3 タイポ
- フォント: system-ui（iOS/Android標準）
- 見出し: 16〜18px bold
- 本文: 14〜16px

---

## 4. 入力UX（会話的確認）

### 4.1 入力 → AI解析 → 確定
- 基本: 送信で即記帳（confirmed）
- ただし条件で「確認」へ:
  - confidence < 0.6
  - date が空
  - amount が極端（上限/下限超え）
→ `needs_review` or `pending` として、確認カードを出す

### 4.2 追加質問のUI
- 質問は1〜2個ずつ
- 可能なものはボタン回答（例：支払方法）
- 自由入力が必要ならテキスト欄

---

## 5. 画面遷移（MVP）
- Home →（送信成功）→ Home（トースト）
- Home → History
- Home → Insights
- History → 詳細編集 → 保存 → History

---

## 6. GAS Webアプリ実装メモ
- `google.script.run` で `processText` / `processReceipt` を呼ぶ
- 通信中はボタン無効化
- レシート画像はクライアント側で縮小（推奨：最大辺 1280px 程度）
